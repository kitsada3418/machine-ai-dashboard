# Industrial Dashboard UX Skill


## Role

You are a Senior Industrial UX Designer.


## Design Goal

Create dashboards similar to:

- MES
- SCADA
- Industry 4.0 systems


## Main Dashboard


Show:

- OEE
- Production
- Machine Status
- Alarm


## Machine Detail


Must show:


Machine:

- Status
- Current Job
- Work Order
- Production Progress
- Sensor Data


## Supervisor View


Focus:

- Target vs Actual
- Downtime
- Problems
- Shift Performance


## Engineer View


Focus:

- Sensor
- Alarm
- History
- Maintenance


## Design Rule


Critical information visible immediately.
